# Typed deciders audit

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.23676316.svg)](https://doi.org/10.5281/zenodo.23676316)
[![arXiv](https://img.shields.io/badge/arXiv-2610.36311-b31b1b.svg)](https://arxiv.org/abs/2610.36311)

Code, derived measurements, preregistration notes and formal proofs for the article [*Confidence Is Not a Promise: A Reference Audit of Typed Decision Models*](https://arxiv.org/abs/2610.36311), by Pedro Carvalho Brom (arXiv:2610.36311). The article compares Laya, an open-weight typed decision model, with Jev 1.13, available only through an API, and asks what the probability of a typed decision licenses and what a gate built on it can promise.

The frozen answers of both deciders, with a datasheet, are released as a separate reference package (`pacote/README.md` and `pacote/DATASHEET.md` describe it). Every number of the article can be recomputed from this repository and that package without new API calls, except the analyses listed under *Jev outputs that are not distributed*.

## Layout

| Path | Content |
|---|---|
| `scripts/` | analyses and runs, one folder per front of the article: `drift`, `explicacao` (explanation), `ruido` (noise), `multilingue` (languages), `bateria` (battery of four domains), `m3` (time series), and the static gate at the top level |
| `data/derived/` | measurements produced by the scripts and read by the tables and figures |
| `data/items/` | the items of each experiment, generated with fixed seeds |
| `promise_check/` | a standalone check of a selective-accuracy promise across populations, with its test |
| `proofs/` | Lean 4 proofs of the selective ceiling and of the dynamic gate |
| `preregistration/` | the drift preregistration, the deviations and the implementation notes, written before each run they describe |
| `docs/EXPERIMENTS.md` | what each decider receives, is asked and returns in every experiment, with the training, calibration and test splits (generated by `scripts/docs_experimentos.py`) |
| `pacote/` | description, datasheet and manifest of the reference package |

## Setup

Python 3.12 with NumPy 2.5, SciPy 1.18, pandas 3.0, Matplotlib 3.11, PyTorch 2.10 and Transformers 5.17. Laya is installed from `github.com/NandhaKishorM/laya` (Apache 2.0) at revision `4066d5d5fbf08b66c6757ddeedbd797bd7655bc0`. The M3 analysis also needs statsmodels.

Datasets, model weights and training caches stay outside the repository, in a folder given by the environment variable `TDA_EXTERNAL` (default: `external/` at the root of the repository):

| Subfolder | Content |
|---|---|
| `dados/1.1/` and `dados/massive_1.1_completo/` | MASSIVE 1.1 (FitzGerald et al., 2023), CC BY 4.0 |
| `dados/news_category/` | News Category Dataset (Misra, 2022), CC BY 4.0 |
| `dados/bateria/` | raw files of the battery domains, from their sources |
| `dados/m3/` | the monthly series of M3, from the R package Mcomp 2.8 |
| `laya-pesos/` | Laya checkpoints as released |
| `laya-ajustado/` | fine-tuned checkpoints and caches, written by the scripts |

## Checking a promise

```bash
cd promise_check
python -m pytest -q
```

The test recomputes the thresholds of the static gate and reproduces the plug-in population analysis within four standard errors, reading Jev from `data/raw/jev_{pt,en}_reduzido.json` (decided option, its probability, whether it is right). `pacote/README.md` shows how to check Jev's promise across the 52 locales from the frozen answers.

## Proofs

```bash
lake env lean proofs/SelectiveCeiling.lean
lake env lean proofs/DynamicGate.lean
```

Run from a Lean 4 project with Mathlib.

## Jev outputs that are not distributed

The vendor's customer agreement forbids using Jev's output to train a model that imitates it. The reference package therefore carries, for each Jev answer, only the decided option, its probability and whether it is right. The full probability vectors, the coalition games with every option and the raw API responses are not distributed. The scripts that call the API (`scripts/query_jev.py` and every script whose name starts with `jev_`) need a key in `TYPESAFE_API_KEY`. The following analyses read Jev outputs that are not in this repository, and their results are included in `data/derived/`. Their Laya parts run without them.

- the static gate and its ablations, for Jev: `scripts/population_gate.py`, `scripts/population_gate_divergence.py`, `scripts/ablation_gate.py`, `scripts/metrics.py`, `scripts/deletion.py`, `scripts/rotulos_nao_inferioridade.py`, `scripts/troca_marginal.py`
- `scripts/multilingue/analise_multilingue.py`, `scripts/ruido/analise_ruido.py`, `scripts/auditoria_beta.py`
- `scripts/bateria/analise_bateria.py`, `scripts/bateria/analise_liar2_estado.py`, `scripts/m3/analise_tipados_m3.py`
- `scripts/explicacao/jev_leituras.py`, `scripts/explicacao/parcela_estrutural.py`, `scripts/explicacao/descritivos.py`, `scripts/explicacao/g5.py`
- `scripts/figures.py` and `scripts/tabela_custo.py`, for the Jev parts of their output
- `scripts/externo/analise_externo.py`, for the Jev parts of the external population and the hard distractors (the new Jev answers in `data/derived/externo/jev_*.json` are not distributed)

The texts of Fake.Br are not distributed, because its repository states no licence. Its records keep the identifier of each text in the corpus.
